WARNING: The bundled ingress-nginx controller has HTTP/2 on, which exposes it to
CVE-2026-123007 and CVE-2026-123633 (nginx2root). Upgrades with --reuse-values keep
the defaults of the chart version this release was first installed with, so they do
not pick up the new default. Turn HTTP/2 off with:

  helm upgrade -n {{ .Release.Namespace }} {{ .Release.Name }} skypilot/{{ .Chart.Name }} \
    --version {{ .Chart.Version }} --reuse-values \
    --set ingress-nginx.controller.config.use-http2=false

NOTICE: This release runs the bundled ingress-nginx controller, which is retired
upstream and no longer gets security fixes. Switch to the bundled Traefik
controller, which keeps this release's external address:

  helm upgrade -n {{ .Release.Namespace }} {{ .Release.Name }} skypilot/{{ .Chart.Name }} \
    --version {{ .Chart.Version }} --reset-then-reuse-values \
    --set ingress-nginx.enabled=false --set traefik.enabled=true

--reset-then-reuse-values (Helm 3.14+) applies this chart version's defaults,
including the Traefik settings, and keeps the values you set.
